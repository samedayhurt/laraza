## 2026-07-29 — Census baseline refresh: ACS API now key-gated (methodology note)
- **Source:** U.S. Census Bureau API (https://api.census.gov/data/2024/acs/acs5/subject?get=NAME,S1901_C01_012E,S1701_C02_001E&for=zip%20code%20tabulation%20area:81008), attempted 2026-07-29; dataset discovery via https://api.census.gov/data.json, accessed 2026-07-29.
- **Notes:** `api.census.gov/data.json` confirms ACS 5-year vintages now run through **2024** (2020–2024 release). However, every keyless request to `api.census.gov/data/{2022,2023,2024}/acs/acs5[/subject|/profile]` now returns an HTML page titled **"Missing Key"** instead of JSON — including the exact 2022 URL recorded in `logs/source_index.md` as CTX-003, which worked in Nov 2025. This is a Census access-policy change, not a vintage problem: keyless anonymous querying is no longer permitted. No `CENSUS_API_KEY` exists anywhere in this repo or in the environment. QuickFacts (https://www.census.gov/quickfacts/) also now returns HTTP 403 to scripted/bot requests, so the Nov 2025 QuickFacts refresh path is closed too.
- **Workaround used:** Pulled the same ACS 2024 5-year estimates from Census Reporter's public read-only API (https://api.censusreporter.org/1.0/data/show/acs2024_5yr?table_ids=B19013,B17001,B01003,B23025&geo_ids=86000US81008,86000US81007,86000US81006,86000US81005,16000US0862000,05000US08101), accessed 2026-07-29. Census Reporter redistributes Census Bureau ACS data verbatim and reports `release: acs2024_5yr / years 2020-2024`. Because it does not serve subject tables (S1901/S1701), income comes from detail table **B19013_001** (median household income) and the poverty rate is computed as **B17001_002 / B17001_001** rather than from S1701.
- **Follow-up:** Register a free Census API key at https://api.census.gov/data/key_signup.html and store it outside the repo (env var, not committed) so future refreshes can use the official subject-table endpoint and stay methodologically identical to the 2022 pull. Until then, label all post-2025 census figures with the B-table method.

- **Notes:** The EVRAZ era is over. On **2026-07-16** the **$1.2 billion long rail mill officially began operations** — 1.1M tons/yr EAF steel, 100-meter (328-ft) rails needing 80% fewer welds, powered by ~750,000 on-site solar panels supplying up to 95% of facility electricity. - **Risk read:** This is the single biggest *positive* economic shift since the Feb 2026 baseline and it cuts against the "Pueblo is only losing" narrative. ## 2026-07-29 — GOVERNANCE CORRECTION: council is 4 districts + 3 at-large, not nine districts
- **Source:** City of Pueblo official site, District 1 Representative page (https://www.pueblo.us/577/District-1-Representative), accessed 2026-07-29; City of Pueblo Charter (https://www.pueblo.us/DocumentCenter/View/21743/CityCharter and https://www.pueblo.us/129/City-Charter); Colorado Politics, 2025-10-21 (https://www.coloradopolitics.com/2025/10/21/pueblo-to-vote-on-strong-mayor-government-sales-tax-and-four-city-council-seats-on-november-ballot/).
