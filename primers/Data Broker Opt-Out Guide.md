# Data Broker Opt-Out Guide

Protect yourself from doxing, stalking, and surveillance by removing your information from people-search websites and data brokers. This guide provides a prioritized approach with direct opt-out links.

---

## Why This Matters

Data brokers collect and sell your personal information - name, address, phone number, relatives, employment history, and location data. This data is used by:

- **Police without warrants** (Fog Data Science, Babel Street)
- **ICE/CBP for immigration enforcement**
- **Stalkers and abusers** finding victims
- **Employers** screening candidates
- **Scammers** targeting individuals
- **Doxers** exposing activists

As of April 2025, there are **750+ unique data broker groups** operating in the United States.

## Step-by-Step Process

### How To Opt Out (General Process)

```
MANUAL OPT-OUT WORKFLOW
=======================

1. SEARCH FOR YOURSELF
   • Google: "your name" + city
   • Check each data broker site directly
   • Note every URL where you appear

2. SUBMIT OPT-OUT REQUESTS
   • Use the links above
   • Most require email verification
   • Some require photo ID (be cautious)
   • Screenshot each submission

3. VERIFY REMOVAL (After 2-4 weeks)
   • Re-search yourself on each site
   • Re-submit if still appearing
   • Document any refusals

4. SET REMINDERS
   • Re-check every 3-6 months
   • Your data WILL re-appear
   • This is ongoing maintenance
```

### Information You'll Need

Keep this ready for opt-out forms:

- Full legal name (and variations, maiden name)
- Current address
- Previous addresses (last 5-10 years)
- Date of birth
- Phone numbers (current and previous)
- Email addresses (all of them)

### What NOT To Provide

- **Social Security Number** - No legitimate opt-out requires this
- **Government ID photos** - Most don't need this; be suspicious
- **Payment information** - Opt-outs should always be free
- **Passwords** - Never share passwords

## Special Situations

### High-Risk Individuals

If you're at elevated risk (activist, journalist, survivor of abuse, immigrant):

```
ENHANCED PROTECTION STEPS
=========================

□ Complete ALL Tier 1 and 2 opt-outs
□ Use mail forwarding service (not home address)
□ Register domains with privacy protection
□ Remove yourself from voter registration public view (if possible)
□ Use Google Voice number instead of real phone
□ Set up Google Alerts for your name
□ Consider legal name variation (middle name as first)
□ Request removal from property records (varies by county)
□ Use PO Box for all public-facing accounts
```

### Credit Freeze vs. Fraud Alert

| Protection | What It Does | Who Sees |
|------------|--------------|----------|
| **Credit Freeze** | Blocks new credit applications | Only you (with PIN) |
| **Fraud Alert** | Requires identity verification for new credit | Creditors must verify |

**Recommendation for activists**: Do a credit freeze at all three bureaus:
- Equifax: [equifax.com/personal/credit-report-services/credit-freeze](https://www.equifax.com/personal/credit-report-services/credit-freeze/)
- Experian: [experian.com/freeze/center.html](https://www.experian.com/freeze/center.html)
- TransUnion: [transunion.com/credit-freeze](https://www.transunion.com/credit-freeze)

### California DELETE Act (Coming 2026)

If you're in California, starting in 2026 you can submit ONE request to remove data from ALL registered brokers via the state's "DROP" (Deletion and Request Opt-Out Portal).

Other states may follow. Check your state's attorney general website for current options.

## Location Data Brokers (High Priority)

These are the companies selling your phone's location to police:

| Broker | What They Sell | Known Clients |
|--------|----------------|---------------|
| **Venntel** (Gravy Analytics) | App location data | ICE, CBP, IRS, DEA |
| **Babel Street** | Locate X tracking tool | ICE, CBP, Secret Service |
| **Fog Data Science** | 250M+ device locations | 1,000+ local police agencies |
| **X-Mode/Outlogic** | Real-time location | DIA, military contractors |
| **Mobilewalla** | Movement patterns | Marketing, police |

### How To Protect Against Location Brokers

These companies get data from apps on your phone. Steps to cut them off:

```
LOCATION DATA PROTECTION
========================

1. AUDIT APP PERMISSIONS
   □ Settings → Privacy → Location Services
   □ Set all apps to "Never" or "While Using"
   □ Delete apps you don't actively use

2. RESET ADVERTISING ID
   iPhone: Settings → Privacy → Tracking → Toggle off
   Android: Settings → Privacy → Ads → Delete advertising ID

3. OPT OUT OF AD PERSONALIZATION
   iPhone: Settings → Privacy → Apple Advertising → Turn off
   Android: Settings → Google → Ads → Opt out of personalization

4. DISABLE BACKGROUND APP REFRESH
   iPhone: Settings → General → Background App Refresh → Off
   Android: Settings → Apps → [App] → Battery → Restricted

5. TURN OFF WIFI/BLUETOOTH SCANNING
   When not actively using WiFi or Bluetooth, turn them fully off
   (not just disconnected)

6. USE VPN
   Masks IP address from advertisers
   Recommended: Mullvad, ProtonVPN, IVPN

7. CONSIDER ALTERNATIVE PHONES
   GrapheneOS (privacy-focused Android)
   Removes Google tracking entirely
```

### FTC Enforcement (2024)

Good news: The FTC banned X-Mode and InMarket from selling precise location data (January 2024), and Gravy Analytics/Venntel and Mobilewalla (December 2024) from selling data tied to sensitive locations.

Bad news: Enforcement is slow, and many brokers remain unregulated.
