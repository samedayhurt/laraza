# Documentation

Reference material that explains processes, inventories active research, and stores public-facing artifacts (agendas, maps, watchlists). Start here when you need background before writing or briefing others.

## Printable Handouts

The `handouts/` folder contains print-ready materials for community distribution:

| Resource | Language | Description |
| --- | --- | --- |
| [KYR-ICE-English.md](handouts/KYR-ICE-English.md) | English | Know Your Rights guide for ICE encounters |
| [KYR-ICE-Spanish.md](handouts/KYR-ICE-Spanish.md) | Spanish | Conoce Tus Derechos - guía para encuentros con ICE |
| [Emergency-Contacts-Card.md](handouts/Emergency-Contacts-Card.md) | Bilingual | Wallet-sized emergency contacts (2 per page, cut & carry) |

**Printing tips:**
- Print KYR guides single-sided for posting
- Emergency cards print 2-up; cut on dotted line
- Laminate wallet cards for durability
