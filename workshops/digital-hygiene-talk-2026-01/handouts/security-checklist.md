# Security Checklist

**For journalists, activists, and organizers**

Print this. Post it. Use it.

---

## Do Today (15 minutes total)

### Phone
- [ ] **Location permissions** → Set to "Never" for social media, games, shopping, news
- [ ] **Advertising ID** → Delete (iPhone: Privacy → Tracking OFF | Android: Privacy → Ads → Delete)
- [ ] **PIN** → Change to 6+ digits (not birthday, not 123456)
- [ ] **Signal** → Install, enable Screen Security, Registration Lock, Disappearing Messages

### Computer
- [ ] **Disk encryption** → Verify ON
  - Mac: System Preferences → Security & Privacy → FileVault
  - Windows: Settings → Update & Security → Device encryption (or BitLocker)
- [ ] **Browser** → Switch to Firefox or Brave
- [ ] **uBlock Origin** → Install extension

### Emergency
- [ ] **Save CORRN**: 844-864-8341 (ICE activity, detention)
- [ ] **Save RMIAN**: (303) 866-9308 (detention hotline)

---

## Do This Week

### Social Media
- [ ] **Facebook** → Settings → Privacy → Limit past posts → "Limit"
- [ ] **Facebook** → Settings → Location → Turn OFF location history
- [ ] **Instagram** → Settings → Privacy → Private Account → ON
- [ ] **Instagram** → Settings → Privacy → Activity Status → OFF
- [ ] **All platforms** → Remove apps/websites you don't use

### Data Brokers
- [ ] **Search yourself** on Spokeo, WhitePages, BeenVerified
- [ ] **Opt out** of TruePeopleSearch.com/removal (instant)
- [ ] **Opt out** of FastPeopleSearch.com/removal (instant)

### Backup
- [ ] **Computer** → Set up encrypted local backup
  - Mac: Time Machine + encrypt
  - Windows: File History or third-party with encryption
- [ ] **Phone** → Review iCloud/Google backup settings
  - Consider: disable Messages, Photos backup for sensitive use

---

## Monthly Maintenance (10 minutes)

- [ ] **Reset advertising ID** (breaks tracking continuity)
- [ ] **Review app permissions** (delete apps you don't use)
- [ ] **Check for software updates** (phone + computer)
- [ ] **Clear browser cookies** (or use containers)

---

## Quarterly (30 minutes)

- [ ] **Re-run data broker opt-outs** (data reappears)
  - Spokeo, WhitePages, BeenVerified, TruePeopleSearch, FastPeopleSearch
- [ ] **Full social media audit** (who can see what, what's tagged)
- [ ] **Check haveibeenpwned.com** (email in breach? change password)
- [ ] **Review cloud storage** (what's there? still need it?)

---

## Before Sensitive Situations

**Protests, ICE-active areas, source meetings:**

- [ ] **Disable Face ID / fingerprint** (use PIN only)
- [ ] **Update phone** to latest version
- [ ] **Enable airplane mode** when not actively needed
- [ ] **Know Emergency SOS** location (iPhone: side button 5x)
- [ ] **Consider**: burner phone, leave phone at home, Faraday bag

**If phone is seized:**
1. Do NOT unlock
2. Say: "I do not consent to a search"
3. Give PIN only if ordered by judge (with lawyer present)

---

## For Organizing Work

### Communications
- [ ] **Use Signal** for sensitive coordination (not WhatsApp, not SMS)
- [ ] **Disappearing messages** ON for organizing chats
- [ ] **Separate account** for public-facing organizing (different email, don't link to personal)

### Meetings
- [ ] **In-person** for most sensitive planning
- [ ] **Signal group** for logistics (not Facebook events)
- [ ] **Assume** public Facebook events are monitored

### Documentation
- [ ] **Video police/ICE** (legal in Colorado public spaces)
- [ ] **Hash files immediately**: `sha256sum filename` (creates tamper proof record)
- [ ] **Upload to secure cloud** before leaving scene
- [ ] **File complaints** with badge numbers, timestamps, witness statements

## Computer Compartmentalization

| Purpose | Tool |
|---------|------|
| **Daily browsing** | Firefox + uBlock Origin (not logged in) |
| **Logged-in accounts** | Separate Firefox profile or different browser |
| **Sensitive research** | Brave private window or dedicated profile |
| **Maximum privacy** | Tor Browser |

---

## What Doesn't Matter (Don't Obsess)

- Deleting old social media posts (already scraped by brokers)
- Perfect privacy settings (platforms change them)
- Fake names on social media (easily correlated via network)
- Trying to be "invisible" (unrealistic, focus on reducing exposure)

---

## What Matters Most

1. **Location data** → Single biggest exposure vector
2. **Disk encryption** → Protects everything if device seized
3. **Signal** → Actually private messaging (WhatsApp isn't)
4. **Biometrics rule** → PIN before sensitive situations
5. **Data brokers** → Your dossier is for sale, opt out regularly
