## How to Use These Materials

### Planning a Workshop

1. **Choose your workshop** from the available options above
2. **Review the event-copy folder** for promotional text in various tones
3. **Customize for your venue** - update dates, locations, contact info
4. **Print handouts** at least 2 days before the event
5. **Test any tech** you'll be demonstrating (Signal, settings screens, etc.)

### Promoting the Event

Each workshop includes promotional copy in multiple tones:

| File | Best For |
|------|----------|
| `flyer-content.md` | Printed flyers, bulletin boards |
| `event-page-text.md` | Facebook events, Eventbrite |
| `one-paragraph-pitch.md` | Text messages, social posts |
| `academic-tone.md` | Grant applications, university partnerships |
| `grassroots-tone.md` | Community organizations, mutual aid networks |
| `press-release.md` | Media outreach, newspapers |

### During the Workshop

- **Arrive 30 minutes early** to set up
- **Have printed handouts** at each seat
- **Leave time for Q&A** - people will have questions
- **Offer 1-on-1 help** after for hands-on device setup
- **Collect Signal contact** for follow-up group (opt-in only)

### After the Workshop

- **Send follow-up resources** via Signal group
- **Share the workshop recording** if captured (with consent)
- **Collect feedback** to improve future sessions
- **Document attendance** for grant reporting if applicable

## Creating New Workshops

Use the `templates/` folder to start new workshops. Key considerations:

1. **Scope it tightly** - 2 hours max for general audience
2. **Lead with WHY** - connect to real threats people face
3. **Hands-on time** - people learn by doing
4. **Bilingual materials** - Spanish translations are essential for Pueblo
5. **Take-home resources** - handouts they can share with family

## Workshop Guidelines

### Accessibility
- Choose ADA-accessible venues
- Provide materials in large print if requested
- Have Spanish-language handouts available
- Consider childcare needs

### Security
- Don't collect unnecessary personal data from attendees
- Offer Signal-only registration as alternative to email
- Don't photograph attendees without explicit consent
- Store any collected information securely

### Safety
- Have a plan if ICE or police arrive
- Know your venue's emergency exits
- Designate someone to monitor the entrance
- Don't publicize specific attendee names
